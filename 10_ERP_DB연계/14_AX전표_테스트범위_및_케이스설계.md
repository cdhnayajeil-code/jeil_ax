## 1. ★ 테스트 범위 정의

### 1.1 원칙

**"사람이 ERP 회계모듈 「결의전표 입력」 화면에서 직접 입력한 전표"** 만 대상이다.

법인카드 연동, 타모듈(구매·영업·자금·자산) 연동, 배치로 들어온 데이터는 **전부 제외**한다.
그 경로들은 각자의 래퍼가 서브원장 처리를 이미 수행하고 있으며, AX 릴레이가 재현할 대상이 아니다.

### 1.2 DEMO2 결의전표 전수 분류

| # | 생성 경로 | 전표수 | 판별 조건 | 대상 |
|:--:|---|---:|---|:--:|
| **①** | **결의전표 수동입력** | **12,085** | `GL_INPUT_TYPE='TG'` + `TRANS_TYPE` 공란 + **A_BATCH 미경유** | ✅ **테스트 범위** |
| ② | 법인카드 정산 (배치) | 474 | 위와 같으나 **A_BATCH 경유** · `REF_NO='IF…'` | ❌ 제외 |
| ③ | 법인카드 연동 | 5,387 | `TRANS_TYPE='AN005'` | ❌ 제외 |
| ④ | 타모듈 연동 | 4,044 | `GL_INPUT_TYPE` ∈ `UX`·`AP`·`AR`·`FN`·`AQ`·`PR`·`LN`·`DP` … | ❌ 제외 |
| ⑤ | AX 릴레이 | 11 | `TRANS_TYPE='AX001'` | — (결과물) |

### 1.3 ⚠️ v1 대비 정정 사항

초판(v1)은 **`TRANS_TYPE` 공란 = 수동입력**으로 잡아 12,559건을 범위로 삼았다.
**그중 474건이 법인카드 정산 배치분**이었다.

```
TG202505230030  REF_NO=IF2025052700006  "5월 법인카드 정산서"
TG202505220030  REF_NO=IF2025052900024  "법인카드 정산 件(5월 19일~22일 중국출장)"
TG202504300126  REF_NO=IF2025050700016  "4월 법인카드 정산의 件 (국내 사용분)"
```

`TRANS_TYPE` 은 비어 있지만 `A_BATCH` 를 경유했고 `REF_NO` 가 인터페이스 번호(`IF…`)다.
**`TRANS_TYPE` 만으로는 수동입력을 가려낼 수 없다.**

### 1.4 판별 기준 — 두 가지가 일치한다

수동입력 12,085건은 **REF_NO 가 100% 자기 전표번호**다. 예외 0건.

| 기준 | 조건 | 결과 |
|---|---|---|
| **A** A_BATCH 미경유 | `NOT EXISTS (SELECT 1 FROM A_BATCH WHERE TEMP_GL_NO = T.TEMP_GL_NO)` | 12,085 |
| **B** REF_NO = 자기 전표번호 | `T.REF_NO = T.TEMP_GL_NO` | 12,085 |

두 기준이 정확히 같은 집합을 가리킨다. 실무에서는 **B가 간편**하다.

```sql
-- 테스트 범위 판별 (표준)
SELECT T.*
FROM   A_TEMP_GL T
WHERE  T.GL_INPUT_TYPE = 'TG'
  AND  ISNULL(RTRIM(T.TRANS_TYPE),'') = ''
  AND  T.REF_NO = T.TEMP_GL_NO;          -- ← 수동입력 표식
```

## 4. 🔴 미결(`OC`) — 판정 기준이 다르다

범위 내 2위 유형(24.6%)이고 **서브원장 생성 경로가 다르다.**

### 4.1 무엇이 다른가

| 구분 | `AP` · `TP` 등 | **`OC` (미결)** |
|---|---|---|
| 대상 원장 | `A_OPEN_AP` · `A_VAT` | **`A_OPEN_ACCT`** |
| 키 | `TEMP_GL_NO` | **`GL_NO`** (정식전표번호) |
| 생성 시점 | 결의 단계 | **승인 후 회계전표 단계** |
| 생성 주체 | `usp_a_create_temp_gl_subsys` | `usp_a_create_gl_subsys` (ERP 승인 경로) |
| `SUBSYS_NO` | 채워짐 | **비어 있는 것이 정상** |

`usp_a_create_temp_gl_subsys` 커서가 `SUBSYS_TYPE NOT IN ('OC','OD')` 로 **미결을 명시 제외**한다.
릴레이가 SP 를 불러도 `OC` 라인은 처리되지 않는다 — **그게 설계다.**

## 6. 공통 검증 쿼리

```sql
DECLARE @slip nvarchar(18) = 'AG20260901xxxx';

-- ① 헤더
SELECT TEMP_GL_NO, CONF_FG, ISNULL(NULLIF(RTRIM(GL_NO),''),'(미승인)') AS 회계전표,
       DR_AMT, CR_AMT, TRANS_TYPE, GL_INPUT_TYPE, REF_NO
FROM   A_TEMP_GL WHERE TEMP_GL_NO = @slip;

-- ② 라인 + 연결번호   ※ OC 계정은 연결번호가 비어 있어야 정상
SELECT I.ITEM_SEQ, I.ACCT_CD, LEFT(A.ACCT_NM,20) AS 계정명, I.DR_CR_FG, I.ITEM_AMT,
       ISNULL(NULLIF(RTRIM(A.SUBSYS_TYPE),''),'-') AS 계정서브시스템,
       ISNULL(NULLIF(RTRIM(I.SUBSYS_NO),''),'(비어있음)') AS 연결번호,
       ISNULL(NULLIF(RTRIM(I.BP_CD),''),'-') AS 거래처
FROM   A_TEMP_GL_ITEM I JOIN A_ACCT A ON A.ACCT_CD = I.ACCT_CD
WHERE  I.TEMP_GL_NO = @slip ORDER BY I.ITEM_SEQ;

-- ③ 서브원장 5종
SELECT '채무 A_OPEN_AP'  AS 원장, COUNT(*) AS 행수 FROM A_OPEN_AP WHERE TEMP_GL_NO = @slip
UNION ALL SELECT '부가세 A_VAT',   COUNT(*) FROM A_VAT     WHERE TEMP_GL_NO = @slip
UNION ALL SELECT '채권 A_OPEN_AR', COUNT(*) FROM A_OPEN_AR WHERE TEMP_GL_NO = @slip
UNION ALL SELECT '선급 F_PRPAYM',  COUNT(*) FROM F_PRPAYM  WHERE TEMP_GL_NO = @slip
UNION ALL SELECT '선수 F_PRRCPT',  COUNT(*) FROM F_PRRCPT  WHERE TEMP_GL_NO = @slip;

-- ④ 미결원장 (OC 케이스 · 승인 후에만 · GL_NO 기준)
SELECT O.GL_NO, O.GL_SEQ, O.ACCT_CD, O.MGNT_CD1, O.MGNT_VAL1, LEFT(ISNULL(O.GL_DESC,''),30) AS 적요
FROM   A_OPEN_ACCT O JOIN A_TEMP_GL T ON T.GL_NO = O.GL_NO
WHERE  T.TEMP_GL_NO = @slip;

-- ⑤ 정식장부 연결번호 승계 (승인 후)
SELECT G.ITEM_SEQ, G.ACCT_CD, G.DR_CR_FG, G.ITEM_AMT,
       ISNULL(NULLIF(RTRIM(G.SUBSYS_NO),''),'(비어있음)') AS 연결번호
FROM   A_GL_ITEM G JOIN A_TEMP_GL T ON T.GL_NO = G.GL_NO
WHERE  T.TEMP_GL_NO = @slip ORDER BY G.ITEM_SEQ;
```

### 판정 기준

| 계정 서브시스템 | 연결번호 | 서브원장 |
|:--:|---|---|
| `AP` · `TP` · `TR` · `AR` · `PP` · `PR` · `SS` | **채워져야 정상** | 결의 단계 생성 |
| **`OC` · `OD`** | **비어야 정상** | 승인 후 `A_OPEN_ACCT` |
| (공백) | 비어야 정상 | 대상 아님 |

### 참조 케이스 재현용 — 범위 내 전표 조회

```sql
-- 특정 조합의 수동입력 전표 찾기 (예: OC)
SELECT TOP 20 T.TEMP_GL_NO, CONVERT(varchar(10),T.TEMP_GL_DT,120) AS 전표일,
       T.DR_AMT, LEFT(ISNULL(T.TEMP_GL_DESC,''),40) AS 적요
FROM   A_TEMP_GL T
WHERE  T.GL_INPUT_TYPE='TG' AND ISNULL(RTRIM(T.TRANS_TYPE),'')=''
  AND  T.REF_NO = T.TEMP_GL_NO                              -- 수동입력 표식
  AND  EXISTS (SELECT 1 FROM A_TEMP_GL_ITEM I JOIN A_ACCT A ON A.ACCT_CD=I.ACCT_CD
                WHERE I.TEMP_GL_NO=T.TEMP_GL_NO AND A.SUBSYS_TYPE='OC')
ORDER BY T.TEMP_GL_DT DESC;
```
