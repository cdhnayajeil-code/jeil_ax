📖 폴더 사용법

▶ 관리 규칙

  • 기준 변경(조직·권한·ERP매핑·프로세스) → 01_기준정보_레지스트리
  • 문서 추가·이동·상태변경 → 00_문서대장
  • 모든 의미 있는 변경 → 03_변경관리_CHANGELOG 한 줄
  • 운영현황(배포·계정·시크릿) → 이관/00_현황스냅샷
  • .md 수정 후 python _build_html.py로 HTML 재생성
  • 이어서 python _build_index_bundle.py — 이 index.html 한 파일에 문서 전문을 다시 심는다(단일 파일 전달본)

⚠ 가드레일

• 비밀값 금지 — Secret·DB접속·키는 이름·존재만 기록. 값은 환경변수/시크릿 매니저에만(CLAUDE.md §1).

• 단일 출처 유지 — 같은 사실을 두 문서에 중복 기록하지 않는다. 포인터로 연결.

• HTML은 빌드 산출물 — MD가 원본. index.html만 직접 관리.
