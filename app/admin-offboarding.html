축별 처리 방식

ERP 자동 · 실증

SharePoint 목록 「ERP 퇴사처리 RPA」에 한 줄 등재하면 기존 Power Automate 흐름이 1분 내 처리합니다. 계정명에 (퇴사)를 붙이고 USE_YN='N', 역할을 회수합니다.

그룹웨어 자동 · 실증

관리자 화면 자동화 스크립트가 처리합니다. 기준일자 이동·퇴사일 복원·메일 삭제 방지를 매번 확인하므로 사람이 놓치던 것을 빠뜨리지 않습니다.

MS(Entra) 자동 · 실증

로그인 차단 + 표시이름 [퇴사] 접두 + 라이선스 회수를 함께 합니다. 그룹으로 상속된 라이선스는 API 로 뗄 수 없어 남았다고 결과에 표시합니다 — 그건 그룹에서 사용자를 빼야 합니다.

예약 목록 
      
        
        
      
    

    

      예약은 일시가 되면 그 시점 기준으로 대상을 다시 산정해 처리 큐에 넣습니다(예약 뒤 인사 반영·계정 정리가 생겨도 옛 정보로 조작하지 않습니다).
      자동 적용은 큐 투입까지 자동이고, 실제 처리는 러너가 켜져 있을 때 됩니다 — 러너가 꺼져 있으면 큐에서 기다렸다가 켜지는 순간 실행됩니다.
      도래 후 7일이 지나도록 실행되지 못한 자동 건은 자동을 풀고 「확인 필요」로 돌리고, 큐에 들어간 뒤 7일이 지나도 러너가 집지 못한 건은 실행하지 않고 실패로 닫습니다.
      자동 적용이라도 도래 시점에 인사상 재직 중이거나 퇴사일이 아직인 사람이 있으면 자동으로 처리하지 않고 「확인 필요」로 돌립니다(퇴사 철회 대비).

처리 절차

    

      
대상 확인 — 위 표에서 이름·이메일·퇴사일을 확인합니다.
        동명이인이 있으므로 이메일까지 봐야 합니다(실사례: 박준수 js.park2/js.park4).

      
ERP — SharePoint 목록 「ERP 퇴사처리 RPA」에 등재합니다.
        사용자 ID=이메일 · 사용자명=부서_이름 · 퇴사일자 ·
        진행구분 = -
        (비워 두면 흐름이 조용히 지나갑니다 — 실패로도 안 뜹니다)

      
그룹웨어 — 위 표의 명령 버튼으로 명령을 만들고 러너에서 실행합니다.
        --apply 없이 먼저 돌리면 저장 직전 상태만 보여줍니다(점검용).

      
MS — 자동 처리됩니다(로그인 차단 · [퇴사] 접두 · 라이선스 회수).
        그룹 상속 라이선스가 있으면 결과에 남으니, 그때만 해당 그룹에서 사용자를 빼주세요.

      
확인 — ERP 연동 현황에서 「데이터 업데이트」를 한 번 돌리면
        세 원천을 다시 받아와 이 목록에서 자동으로 빠집니다.

      
예약(선택) — 지금이 아니라 정한 일시에 처리하려면 검색에서 대상을 고르고 ⏰ 예약에 일시를 넣습니다.
        「자동 적용」을 켜면 일시가 됐을 때 확인 없이 큐에 들어가고, 끄면 「도래 — 확인 필요」로 떠서 「지금 적용」을 눌러야 갑니다.
        ERP 축은 러너가 실행하는 시점에 SharePoint 에 등재되고 약 1분 안에 비활성(USE_YN=N)됩니다 — 러너가 꺼져 있으면 켠 뒤에 반영됩니다.

    


    
안전 규칙

    

      되돌리기 어려운 작업입니다.
      
    
        
  • ERP 흐름은 사용자 역할을 DELETE 하고 무엇이 있었는지 남기지 않습니다 — 등재 전에 역할 목록을 적어 두세요.
    • 
        
  • 그룹웨어의 「메일 삭제여부」 체크박스는 절대 켜지 마세요(메일계정·메일정보 일괄 삭제). 자동화 스크립트는 켜져 있으면 저장하지 않고 멈춥니다.
    • 
        
  • 그룹웨어는 사용중지 시 퇴사일이 오늘 날짜로 덮어써집니다 — 실제 퇴사일로 되돌린 뒤 저장해야 합니다.
    • 
        
  • MS 라이선스를 회수하면 사서함이 30일 보존 후 삭제됩니다(Microsoft 정책).
            되돌리려면 그 기간 안에 같은 라이선스를 다시 할당해야 합니다.
    • 
        
  • 계정 삭제는 이 화면의 범위가 아닙니다. 차단·표기·라이선스 회수까지만 합니다.
