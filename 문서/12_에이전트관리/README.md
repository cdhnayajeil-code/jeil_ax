**갱신 규칙**
- 에이전트 설정·구성원·모델·배포 버전·DB 가 바뀌면 `00_현재상태` 를, 작업을 하면 `03_진행상태_변경이력` 을 갱신한다.
- `.md` 를 고친 뒤 `python 문서/12_에이전트관리/_build_html.py` 로 HTML 을 재생성한다(`index.html` 은 직접 관리). 이 빌드가 `06` 을 `app/agent-templates.json` 에서 **다시 생성**하므로 06 은 손으로 고치지 않는다 — 템플릿을 바꾸려면 JSON 을 고친다(콘솔 「📐 관리 포인트·템플릿」 탭도 같은 파일을 읽는다).
- **지시문(시스템 프롬프트)** 은 `supabase/functions/jeil-chat-lab/core/prompt.ts` 가 정본이다(공통 절·도메인 안내). 고치면 `node _test_prompt_assembly.mjs` 로 회귀를 돌리고 `node _gen_gateway_prompt.mjs` 로 운영 지시문 정본 SQL 94 를 다시 만든다 — 운영 DB 지시문을 콘솔에서 손으로 고치지 않는다(2026-10-07 · 09 문서).
- 시스템 전체 상태(배포·DB)는 이관 관제(`실제구축준비 자료/이관/`)에도 한 줄 남긴다 — 여기는 에이전트 관점의 상세.
- 비밀값(API 키 값·시크릿)은 여기에도 적지 않는다(CLAUDE.md §1). 키 **이름**만 적는다.
