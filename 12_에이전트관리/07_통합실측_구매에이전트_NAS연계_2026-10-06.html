3-4. NAS 연계에서 발견한 결함

번호내용영향권고
N-1워커 2대가 각자 색인을 갖고 있어 문서 번호가 서로 다릅니다. 같은 번호 「구매팀:7」을 읽으면 컨테이너는 체크리스트를, PC 워커는 평가기준 엑셀을 돌려줬고, 「전사공유:1」은 한쪽에서 「없음」이 나왔습니다.검색은 A 워커, 읽기는 B 워커가 답하면 엉뚱한 문서를 읽거나 못 읽습니다. 권한 범위는 지켜집니다(같은 폴더 안에서만).PC 임시 워커를 내리면 해소됩니다(원래 계획된 절차). §9 ①
N-2과거 대화의 일시가 9시간 이른 시각으로 나옵니다(15:03 대화가 06:03으로 표기 — 세계표준시 그대로).사용자가 「언제 물어본 건지」를 잘못 읽습니다.워커에서 한국 시각으로 변환.
N-3실험실 화면의 NAS 결과 카드가 표 머리글·칸을 undefined로 그립니다(도구가 보내는 표 모양이 화면 규격과 다름). 모델의 글 답변은 정상입니다.카드 표를 읽을 수 없습니다. 구매 에이전트 화면에서도 같을 가능성이 높습니다(미확인).NAS 도구 4종의 표 모양을 화면 규격에 맞춤. 에이전트에 켜기 전 필수.
N-4「사내 문서」 질문에 OneDrive 문서 도구와 NAS 문서 도구가 함께 있어 모델이 고르는 쪽이 갈립니다.같은 질문에 답이 달라질 수 있습니다.도구 설명에 구분 기준을 적거나 한쪽으로 묶음.
N-5이름에 「급여」가 든 파일은 내용은 색인되지 않지만 파일 목록에는 이름이 보입니다(이미 알려진 설계).폴더 권한이 있는 사람에게만 보임.허용 폴더에 민감 파일을 두지 않는 운영 원칙 유지.

4. 구매 에이전트 — 실제 대화 27문항

관리자 계정으로 라이브 화면(/work/purchase-agent)에서 물었고, 숫자가 든 답은 중간DB를 직접 조회해 대조했습니다. 38턴 전부 예비 모델(gpt-4.1-mini)이 답했습니다 — 기본 모델(Claude)은 선불 크레딧 잔액 0으로 거부되고 있습니다.

잘하는 것

  • 번호가 정해진 조회 — 발주 상세, 번호 추적, 기안서 연결 추적
  • 월 단위 현황과 매입 순위(도구가 합계를 직접 주는 것)
  • 거래처 하나로 좁힌 미입고 건수·금액
  • 용어 설명, 범위 밖·실거래·개인정보 요청 거부
  • 없는 데이터를 지어내지 않음

틀리는 것

  • 여러 거래처에 걸친 집계·순위(받은 줄이 잘린 채로 계산)
  • 「발주」와 「매입」 구분
  • 금액순 정렬처럼 도구에 없는 정렬을 했다고 말하는 것
  • 품목 이름 검색(낱말 사이에 다른 글자가 끼면 못 찾음)
  • 도구마다 다른 미입고 수치(프로필 vs 미입고 목록)

8. 적용 가능 범위

지금 써도 되는 것

  • 발주·구매요청·결재 번호로 묻는 조회와 진행 추적
  • 기안서 한 건의 연결 추적(스캔본·전표·세금계산서·발주)
  • 이번 달·특정 월 발주 현황, 기간 매입 순위
  • 거래처 한 곳의 납기경과 미입고 건수·금액
  • 번호 체계 등 용어 설명
  • NAS: 매일 적재 · (관리자 실험실에서) 파일 목록·과거 대화·문서 검색

검산하며 써야 하는 것

  • 여러 거래처에 걸친 집계·순위·상위 N — 화면의 표와 맞는지 확인
  • 거래처 프로필의 미입고 수치
  • 「발주 금액」 질문 — 답이 발주인지 매입인지 표 제목으로 확인
  • 기안서 대사 요약(이번 회차 미대조)
  • 보고용 요약 — 숫자는 맞았으나 표시 줄 수 한계가 있음

아직 맡기면 안 되는 것

  • 금액순 등 정렬이 필요한 「가장 큰 N건」
  • 품목 이름 일부로 찾는 검색(없다고 답할 수 있음)
  • 구매 에이전트에서의 사내 문서·규정 질문(도구 미연결)
  • 구매팀 전원 대상 공개 운영
  • 골든셋 통과율을 근거로 한 버전 승격 판단

10. 이번 회차에서 못 한 것

  • 기본 모델(Claude)로의 응답 품질 — 크레딧 문제로 전 턴이 예비 모델이었습니다.
  • 구매 에이전트 화면의 파일 첨부 · 보고서 만들기 · CSV 내려받기 · 자료함 · 평가(👍👎)는 이번에 누르지 않았습니다.
  • NAS 문서 검색의 PDF(특히 한글 PDF) · hwpx · pptx 형식 — 이 PC에 문서 생성 도구가 없어 시험 문서를 만들지 못했습니다.
  • NAS 워커가 꺼졌을 때의 「보관소 점검 중」 응답 — 워커를 끄지 않았습니다(10-02 실측 결과만 있음).
  • 일반 구매팀원 계정으로의 화면 확인 — 관리자 계정으로만 시험했습니다. 부서별 범위는 조회 큐 단계에서 부서를 바꿔 넣어 확인했습니다.
  • 기안서 대사·외주검사 답의 원자료 대조(2문항).

시험 흔적: 구매 에이전트 대화 기록 38턴과 회귀 2회차는 품질 기록으로 남겼습니다. NAS에 넣었던 시험용 가상 문서 8개와 조회 큐 시험 요청 85건은 삭제했습니다. 이 문서에는 NAS 주소·공유 경로·토큰을 적지 않았습니다.
