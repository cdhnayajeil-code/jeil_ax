🔑 ERP 권한정리 사용 안내

팀장·부서장용 · 예시는 총무팀 · 화면 주소 ai.jeilm.co.kr/work/erp-roles

정리하기 — 네 단계면 끝납니다

1 2 3 4
  1. 왼쪽 조직도에서 우리 팀을 클릭 팀 이름을 누르면 오른쪽에 우리 팀 사람과 권한이 나옵니다.
  2. 「권한정리」 탭을 클릭 먼저 「Matrix」 탭에서 누가 어떤 권한을 갖고 있는지 훑어보셔도 됩니다.
  3. 뺄 권한에 체크 가로 = 권한, 세로 = 팀원. 빼야 할 칸을 체크합니다. 권한 이름을 누르면 그 줄 전원이 한 번에 선택·해제됩니다.
  4. 권한확인 완료 입력 후 저장 문구를 정확히 입력해야 저장 버튼이 열립니다. 메모는 선택입니다.
뺄 권한이 없어도 꼭 저장해 주세요. 체크 없이 권한확인 완료만 입력하고 저장하면 「변경없음」으로 기록됩니다. 저장하지 않으면 관리자 화면에서 「아직 확인 안 한 팀」으로 남습니다.

🔑 저장한 뒤 — 확인과 수정

저장하면 화면이 아래처럼 바뀝니다
5 6 7
  1. 초록 띠 = 확인 완료 누가 언제 확인했는지와 제외 건수가 남습니다. 뺄 것이 없었으면 「변경없음」으로 표시됩니다.
  2. 「정리완료」 표시 이미 올린 권한은 줄이 초록으로 바뀌고, 해당 팀원 칸은 체크 대신 ✓ 로 잠깁니다(마우스를 올리면 누가 언제 올렸는지 나옵니다).
  3. 고치려면 수정 잠금이 풀려 다시 체크할 수 있고, 잘못 올린 줄에는 「삭제」 버튼이 생깁니다. 고친 뒤 다시 권한확인 완료를 입력해 저장하세요.
이 화면은 ERP 권한을 실제로 회수하지 않습니다. 「이 권한은 빼 주세요」라고 요청을 남기는 곳입니다. 실제 회수는 관리자가 ERP에서 처리한 뒤 완료로 표시합니다.
자주 묻는 것
· 저장 버튼이 안 눌려요 — 권한확인 완료 를 띄어쓰기까지 똑같이 입력했는지 확인해 주세요.
· 체크가 안 되는 칸이 있어요 — 이미 정리 요청을 올린 칸(✓)입니다. 수정 → 삭제 후 다시 하세요.
· 「확인」 이라고 붙은 권한은 뭔가요 — 팀에서 소수만 가졌거나 다른 부서 업무로 보이는 권한입니다. 참고 표시일 뿐이니, 표시가 없는 권한도 함께 봐 주세요.
